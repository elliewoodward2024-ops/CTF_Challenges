Welcome to the steganography challenges!

This set of challenges is different from the rest and you need a terminal to compleat them.

Commands That May Be Used

cat, strings, grep, exiftool, binwalk, unzip, mv, steghide



To use this set of challenges:

- Click on the challenge card. If you click on hint section it will open, so don't if you want to give it a go first.

- Each challenge has an image, they may look the same but they are different.

- Download each image to be able to do the challenge (Download and navigate to the file in terminal)

- Lastly, once you have the image have a go at the challenge and try to find flags!



In the end if you cannot solve a challenge go to the Answers page in the Menu to have a look at what the answer is and how to get there.
